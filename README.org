#+title: Context Collapse
#+author: Rhea Myers

Social media conversation landscapes.

For "The Stories That We Tell Ourselves Online".

* Running

Open =src/index.html=. No build step, no server, no dependencies.

* Packaging

=make= writes an objkt interactive token per variant into =build/=: a =flat/=
directory holding =index.html= and its scripts under =js/=, beside a =flat.zip= of
the same. =make check= verifies what objkt requires — index.html at
the top of the ZIP, every reference relative, no external requests. Needs GNU make.

This is packaging, not building. Nothing is compiled, minified or transformed;
=src/= still opens from =file://= exactly as it did.
